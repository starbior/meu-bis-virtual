# 🐙 Meu Bis Virtual — Crie seu Bis!

Bem-vindo ao **Meu Bis Virtual**, um jogo web interativo onde você pode criar, personalizar e cuidar do seu próprio **Bis** — um polvo roxo virtual cheio de personalidade!

## 🎮 Ideia do Jogo

- **Crie seu Bis**: Escolha o nome, tom de roxo, expressão dos olhos e acessórios do seu polvo virtual.
- **Cuide do Bis**: Alimente, brinque e coloque o Bis para descansar para manter os níveis de **Fome**, **Alegria** e **Energia** sempre altos.
- **Interaja**: Clique no Bis para fazer cócegas nos tentáculos e ver reações animadas!

## 📁 Estrutura do Projeto

```text
meu-bis-virtual/
├── index.html       # Página principal do jogo
├── css/
│   └── style.css    # Estilos, tema oceânico/roxo e animações do Bis
├── js/
│   └── app.js       # Lógica de customização, status do pet e interações
├── .gitignore       # Arquivos ignorados pelo Git
└── README.md        # Documentação do projeto
```

## 🚀 Como Executar

Como o projeto utiliza **HTML, CSS e JavaScript puro (Vanilla)**, basta abrir o arquivo `index.html` no seu navegador ou usar uma extensão como o **Live Server** no VS Code.
